# webScrapper

## Тестовое задание по веб-скрапингу

### Дисклеймер

Код написан в исследовательских целях.

### Описание задачи

Спарсить объявления с сайта auto.drom.ru.<br/> 
Парсер должен заходить на сайт раз в день и забирать только новые объявления (те, которых нет в нашей базе). При первом заходе парсер должен спарсить объявления за предыдущие N дней.
